# Blog Django

## Introducció

Aquest projecte és un blog desenvolupat amb Django. El projecte permet gestionar posts, autors i tags utilitzant bases de dades relacionals.

## Objectius del projecte

- Crear un blog amb Django
- Mostrar posts dinàmics
- Gestionar autors i etiquetes
- Utilitzar relacions entre models
- Implementar pàgines dinàmiques
- Crear una pàgina 404 personalitzada
